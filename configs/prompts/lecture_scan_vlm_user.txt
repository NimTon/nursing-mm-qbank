**【JSON 结构】** 输出必须是**一个 JSON 对象**，且**必须且仅**包含三个键：`页码`、`章节标题` 与 `lines`。

示例（形状示意；字段须为图中真实文字，勿照抄示例）：

{
  "页码": "153",
  "章节标题": "第一章 绪论",
  "lines": [
    "一、单项选择题",
    "1. 某患者……",
    "A. ……",
    "B. ……"
  ]
}

**页码**
- 字符串：从本页**书眉/页脚/装饰页码行**等辨认的印刷页码，如 `"153"`、`"— 153 —"` 中提取数字部分亦可。
- 本页完全看不到页码时填 `""`。

**章节标题**
- 字符串：本页**顶部**、**单项选择题大题上方**出现的章节/篇名标题（如「第×章 ×××」「篇 × …」）。
- 仅写标题本身，不要附带培训机构广告语。
- **本页未见明确章节标题时填 `""`**（不要猜测、不要从邻页推断）。
- 若标题已写入 `章节标题`，`lines` 中可不再重复抄写该标题行（大题说明如「一、单项选择题」仍应写入 `lines`）。

**lines**
- 字符串数组：**按图中从上到下的阅读顺序，一行对应数组一项**。
- 只抄**本页主体区域**上与**题目/选项/题干**相关的可见文字；**不要**把图片边缘、书缝、上下露出的**邻页**文字抄进来。
- **非常原始**：不按题号归纳；同一道题被截断时，可能只剩题干或只剩选项，**有什么抄什么**；**不要解析/答案讲解**（卷面没有就不要写）。
- 空行、纯装饰线不要输出；单字难辨可用 `□`。
- 多栏排版：先左栏自上而下，再右栏自上而下（若明显双栏）。

**必须过滤、不得出现在 `lines` 中**（与题目无关，一律丢弃）：
- 培训机构标语：如「启峻教育」「让梦想起飞的地方」「让梦想起飞」「启峻教育让梦想起飞的地方!」
- 套话：如「启峻教育祝您考试成功」「祝您考试成功」
- 报名/咨询热线及号码：如「报名热线:17501446985」「报名热线」「咨询热线」+ 电话
- 机构 **Logo**、校徽、水印、重复校名装饰
- 纯装饰页码行若与 `页码` 字段重复，可从 `lines` 省略（页码仍写入 `页码` 键）

除 JSON 外不要输出任何文字。
