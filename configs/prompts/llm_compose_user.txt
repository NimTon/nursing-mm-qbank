下面是一页教材/试卷的**整页转写纯文本**（可能有错字、缺字、顺序略乱、跨页截断；若经 VLM 分类，可能已带 `【问题 n】` / `【解析 n】` 行首标签）。
**忽略** 培训机构标语、书眉页脚装饰页码行、仅「报名/咨询热线」+电话 等与做题无关的噪音，勿写入输出字段（参考启峻/梦想起飞/祝您成功 等类典型广告）。

请拆成若干道「题」，输出一个 JSON 对象，**仅含一个键** `items`，值为数组。每项须含字段（名与上例相同）：
- type: 单选|多选|判断|简答|未知
- stem: 题干（只整理原文可见内容；不臆造）
- options: 字符串数组，无选项则 []
- answer: 能确定的答案（如 A / 对），不能确定则空字符串
- analysis: 该题在本页出现的解析文字；**本页完全无解析或明显缺后半段时，必须只输出空字符串**，不得用常识或教材知识补成「完整解析」
- confidence: 0 到 1 的小数
- incomplete: 布尔。当题干或选项在原文中**不能构成完整一道题**（如跨到下一页、转写截断、题面缺失）时设为 `true`；为 `true` 时：`stem` 与 `options` 只许写**有依据的可见片段**（可部分为空/极短），**不得**为凑成一道完整题而编造、补全、续写；`answer` 无法确定时为空
- incomplete_analysis: 布尔。当本页中该题**无解析、或解析明显被截断/只出现开头**、无法从原文取全解析时设为 `true`；为 `true` 时 `analysis` **必须**是空字符串 `""`，**禁止**用课外知识把解析补全为「长段标准答案」
- note: 字符串，**可选**；有 `incomplete` 或 `incomplete_analysis` 为 true 时建议简短说明原因，如「题干跨页」「本页无解析」。若**题号**在原文中糊/缺、但**上下题题号可辨**，可依据**题号 step=1 连续递增**（后一题 = 前一题 +1）在 `stem` 中补全/理顺题头编号，并在 `note` 写如「题号据相邻题+1 推断」。

**题号规律：** 同一套卷在本页内（及与前后文顺序一致时）题号视为**等差 1、按阅读顺序递增**；在题面/转写中某题题号难读时，优先用**上下题**反推；不可无依据跳号、乱序编号。

重要：出现不完整时以标记为主，**宁可不输出看似完整的题或长解析**，也不要用模型知识伪造完整 `stem`/`analysis`；题号反推**仅**在能由相邻题号推出时使用，不得为凑整卷而虚构不存在的题。
