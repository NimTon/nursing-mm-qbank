**【先遵循此 JSON 结构】** 输出必须是**一个 JSON 对象**，顶层**必须且仅**包含两个键：`items` 与 `composed_items`。

- `items`：用于后续按题号合并与修正（字段：`题号` / `类型`(问题|解析) / `题目类型`(单选|多选|判断|简答|名词解释|填空|案例分析|论述|未知) / `内容`）。
- `composed_items`：直接把本页拆成题库结构（字段同 llm-compose：`type` / `stem` / `options` / `answer` / `analysis` / `confidence` / `incomplete` / `incomplete_analysis` / `note`）。

下面为**形状示例**；实际「内容」须为图中真实文字，勿照抄示例套话（图中没有的内容不要编）。

{
  "items":[
    {"题号": "1", "类型": "问题", "题目类型": "单选", "内容": "1. 下列哪项正确？\nA. 选项A\nB. 选项B"},
    {"题号": "1", "类型": "解析", "题目类型": "单选", "内容": "答案：A。因……（若无解析可填空字符串）"},
    {"题号": "2", "类型": "问题", "题目类型": "判断", "内容": "2. 判断题……"}
  ],
  "composed_items":[
    {"type":"单选","stem":"1. 下列哪项正确？","options":["A. 选项A","B. 选项B"],"answer":"","analysis":"","confidence":0.7,"incomplete":false,"incomplete_analysis":true,"note":""}
  ]
}

**类型**只能是汉字「问题」或「解析」（区分题干块与解析块）；**题号**优先写图中能辨认的编号。

**整页选择题型一致（预处理前提，强制）**
- 本页图像已经预处理：**凡为本页出现的、带 A/B/C/D… 选项的选择题，整页只会是同一种题型**：要么**全部为「单选」**，要么**全部为「多选」**。同一页内所有此类题的 `题目类型`（`items`）与 `type`（`composed_items`）必须彼此一致，禁止混用。
- **先判页型，再填各题**：综合卷面**大题说明/标题**（如「单项选择题」「多项选择题」「以下每题有多个正确答案」）、**解析答案形态**（单字母如「A」多为单选；连续多字母如「AB」「BCD」「ACE」或「正确答案：BD」多为多选）、题干用语（「正确的有」「两项以上」等），判定本页属于**单选页**还是**多选页**，然后对该页**每一道**选择题填同一结果。
- **严禁**：仅凭「有 ABCD 四个选项」就默认「单选」；多选卷同样常用四选项。**严禁**在用户已给「多选题」页的情况下输出成「单选」。
- 若本页实为判断题、简答题等非 A/B/C/D 选择题，则不受「单选/多选」绑定限制；仅对**选项题**执行上述一致规则。
- **题目类型**：同一题号的「问题」「解析」两条必须填**相同**题型字符串（见上文枚举）。在已判定页型的前提下，各选项题不得标成另一种选择题型；仍完全无法区分页型且卷面无线索时整页选项题可填「未知」（应极少见）。

**题号反推（重要）：** 本类试卷的题号在**阅读顺序**上**步长为 1 连续递增**（后一题 = 前一题 +1）。当某题题号**模糊、缺失或难辨**时，可根据**同一阅读顺序**上、下相邻已认清的题号来补全本段 `题号` 字段；若仅能粗判，在合理推断后写入字符串形式的题号。若**整页都无法确定任何参考题号**且无法反推，则 `题号` 可为 `""`。

---

阅读该整页/整屏图，在排除噪音后：

1) 先将**与试题相关**的可见文字按「题号 + 问题/解析」分类到 `items`。
2) 再基于同一页内容，直接拆成题库结构到 `composed_items`。

输出**严格 JSON 对象**（可配合 json_object 模式），且**最外层必须且仅有两个键**：`items`、`composed_items`：

- `items`：数组。每项**必须**包含四键（均为字符串）：`题号`、`类型`、`题目类型`、`内容`。
  - `题号`：如 "1"、"2" 或与图中/反推后一致的题号。用于后处理**按题号**对应同题的「问题」与「解析」；**能根据上下题以 step=1 反推的须尽量给出**，反推的也写入此字段。仅当**无法**建立任何题号时再用空字符串 `""`。
  - `类型`：只许为 `"问题"` 或 `"解析"` 二选一。题干、选项、材料属于「问题」；考后答案讲解、易错、名师解析等属于「解析」。
  - `题目类型`：见上文枚举；同一题号各条须一致。
  - `内容`：本段正文。勿含上述版式广告、页脚电话。无正文时 `""`。

- `composed_items`：数组。每项必须包含键：
  - `type`: 单选|多选|判断|简答|未知（本页所有选项题的 `type` 须与上文「整页选择题型一致」规则一致，不得出现同页有的填单选、有的填多选）
  - `stem`: 题干（只整理原文可见内容；不臆造）
  - `options`: 字符串数组，无选项则 []
  - `answer`: 能确定的答案（如 A / 对），不能确定则空字符串
  - `analysis`: 该题在本页出现的解析文字；本页无解析则空字符串
  - `confidence`: 0 到 1 的小数
  - `incomplete`: 布尔，题干/选项不完整则 true（不得补造）
  - `incomplete_analysis`: 布尔，本页无解析或解析明显截断则 true（为 true 时 analysis 必须是空字符串）
  - `note`: 字符串，可选

阅读顺序：多栏时先左后右、自上而下。同一题号可出现多条 `items`（如一条「问题」+ 一条「解析」）。

**必须整页过滤、不得出现在任何「内容」中** 的版式噪音（与试题无关，一律丢弃）包括且不限于：
- 含「启峻教育」「让梦想起飞的地方」「让梦想起飞」等培训机构标语、重复校名。
- 含「祝您考试成功」等套话。
- 书眉/页脚纯装饰页码行，如「— 153 —」这类仅居中的页码装饰。
- 报名/联系电话类：如「报名热线」「咨询热线」+ 电话数字。只要与做题无关均不得输出。
单字难辨时可用「□」占位。不要编造图中不存在的文句。除 JSON 外不要输出任何文字。
