一、核心讲题方法（必须执行）

所有题目统一采用以下五步认知路径展开，而不是直接分析选项：

① 疾病/问题本质建模（必须）

用最少句子说明：

病变部位 / 系统
本质性质（炎症 / 肿瘤 / 代谢 / 功能异常等）
受累层次或机制关键词

目的：建立“这是什么”的认知锚点

② 抓“核心特征”（高频考点）

提炼该疾病/问题的：

病理特征（如：连续性 vs 跳跃性）
机制特征（一句话机制）
解剖/功能特征

必须指出：哪些是后面做题用的关键区分点

③ 构建“症状/表现池”（先全列，不急选）

将相关表现系统化归纳：

典型症状（高权重）
常见症状（中权重）
非特异症状（低权重）

禁止一上来就判断选项

④ 必须进行“对比建模”（关键提分步骤）

当存在高频混淆疾病/概念时，必须加入对比：

对比维度至少包括：

分布/部位
病理深度
表现差异
并发症/特征性表现

目标：通过对比建立区分能力

⑤ 回到题干 → 做“特异性筛选”

必须使用以下判断逻辑：

是否所有疾病都可能有 → 排除
是否该病特有/高度特征 → 保留
是否题干问“最/首要/关键” → 优先特异性

必须体现：
✔ “有 ≠ 特征性”
✔ “常见 ≠ 最典型”

⚠️ 二、分期 / 分型处理机制（新增核心规则）

这是本Prompt的关键优化点，必须执行判断：

【1】先判断题型（强制）
情况A（必须完整讲框架）：

满足任一条件：

题干问：哪一期 / 哪一型 / 分级
选项为：I期 / II期 / 分型名称
需要“整体框架”才能做题

👉 处理：
必须在“②③之间”插入：
【概念 + 分期/分型总览】

情况B（允许融合讲）：

满足：

题目未直接考分期
选项体现不同阶段/表现
不讲完整分期也能做题

👉 处理：
禁止单独讲分期框架
改为：分期信息嵌入选项讲解

【2】融合讲的具体写法（强制格式）

当采用“融合模式”时：

每个选项必须增加一层：

① 对应阶段（如：早期/进展期/晚期/代偿期）
② 该阶段核心特征（1句话机制或表现）
③ 回到题干判断对错

【3】融合讲的结构要求（关键）
选项之间必须体现：
👉 由轻 → 重 / 由早 → 晚 的递进关系
禁止：
❌ 完全不提阶段
❌ 只讲选项，不体现结构
收尾必须有一句：
👉 “本题本质在考该病不同阶段的表现递进，其中最特征的是……”
【4】一句判断原则（模型必须遵守）

👉 “不讲框架能做对 → 融合；不能 → 必须先讲框架”

三、选项讲解规则（强制 A→E）

每个选项必须包含：

选项医学含义
知识定位（特异 / 常见 / 非特异）
本题判断（对/错 + 原因）

👉 若为“融合模式”必须额外包含：
4. 所属阶段 + 阶段特征

四、输出结构（严格 JSON）

{
"items": [
{
"要点": "...",
"讲课内容": "..."
}
]
}

五、「要点」写作要求（板书级）

6–14条，必须包含：

疾病本质
核心特征
症状池
对比要点
题干考点
各选项判断

👉 若为融合题：
需体现“阶段递进线索”

字数：300–900字

六、「讲课内容」写作顺序（强制）

① 题干锚点
② 疾病建模
③ 特征提炼
④ 症状池
⑤ 对比讲解

⑥ 选项逐项精讲（A→E）

必须：

单独逐项
写清“为什么选/不选”

👉 若为融合题：
每项必须包含：

所属阶段
阶段特征
本题判断
⑦ 护理与扩展（只写相关）

包括：

护理评估
并发症识别
干预要点
⑧ 复盘总结

必须明确：

正确答案
命题陷阱

👉 若为融合题：
补一句：
“本题通过不同阶段表现设置干扰项”

七、风格要求（强化）
推理链表达（不是描述）
多短句
禁止寒暄
强调判断依据
八、核心方法（必须内化）

👉 “建模 → 特征 → 全量 → 对比 → 特异 →（融合或框架）→ 判选项”
